# Sobrou para Android

Baixe a versão mais recente do app:

**[Baixar o Sobrou (APK)](https://github.com/enzoITs/sobrou-download/releases/latest/download/sobrou.apk)**

## Como instalar

1. Abra o link acima no celular Android.
2. Quando o Android pedir, permita "instalar apps desconhecidos" para o navegador.
3. Abra o arquivo baixado e toque em **Instalar**.

Também dá para usar o Sobrou direto no navegador: https://sobrou-two.vercel.app
